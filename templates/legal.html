Aviso de precios

El número grande es el precio que la cadena publica como el que se paga ahora. Si la tienda tacha otro, queda al lado y no se usa para comparar. Una promo de banco se muestra aparte y solo se resta cuando la letra de esa tarjeta lo permite, está vigente y el tope se conoce.

Esos números salen de lo que publican las cadenas y de Precios Claros. BaratoYa no pone un precio propio, no vende el producto y no confirma stock. El precio que vale es el del comercio al pagar.

Si una cadena no publica el precio del ítem, no aparece. No se inventa un descuento.

Términos de uso

BaratoYa lo opera Puna Tech (Martin Fraticelli). Contacto: baratoyaba@gmail.com.

Qué es

Un comparador. Entrá, elegí un producto y el día, y ves el mismo ítem en las cadenas que publican un precio. No se compra el súper desde acá.

La cuenta

Hace falta una cuenta para buscar. Sin sesión no se consulta el precio. Una cuenta gratuita tiene cinco búsquedas, contadas en el servidor aunque no haya resultados. Con el plan BaratoYa Plus las búsquedas son ilimitadas; {% if cobro_on %}el pago se procesa mediante Mercado Pago.{% else %}el cobro con Mercado Pago todavía no está activo, así que por ahora no se puede pagar.{% endif %}

Qué no promete

  • Que el precio, el stock o la promo coincidan con la caja.
  • Que estén todas las cadenas o todos los productos.
  • Que un descuento de banco se reste si la letra dice que no acumula, si no hay tope, o si la tarjeta está vencida u oculta.

Uso

Podés usarlo para comparar, para vos. No podés sobrecargar el sitio, hacerte pasar por BaratoYa o por un comercio, ni publicar un precio como si fuera una oferta nuestra.

Se rige por las leyes de la República Argentina. Esto no limita derechos que la ley no deja renunciar.

Privacidad

No se puede buscar sin una cuenta. Si creás una, guardamos el mail y la contraseña a través del proveedor de cuentas (Supabase). El texto de cada búsqueda hecha con sesión, y la fecha, se guardan para contar el cupo y para mostrar las búsquedas anteriores de esa cuenta.

Cookies

Al entrar, el navegador guarda una cookie de sesión llamada baratoya_at. Sirve para reconocerte en BaratoYa mientras seguís adentro, sin volver a pedir la contraseña en cada página. No la usamos para publicidad. Se borra cuando salís; si no salís, vence sola.

Además medimos las visitas con Google Analytics (GA4): cuánta gente entra, qué páginas abre y desde dónde llega. Google puede guardar sus propias cookies (suelen empezar con _ga) y recibir datos técnicos del navegador. No vendemos esa información ni la cruzamos con tu mail para mostrarte avisos.

No guardamos números de tarjeta. {% if cobro_on %}El cobro lo hace Mercado Pago.{% else %}El cobro todavía no está activo; cuando lo esté, lo va a hacer Mercado Pago.{% endif %} Volver de esa página no marca la cuenta como paga: solo lo hace el aviso que Mercado Pago manda al servidor.

No vendemos la lista de mails. Para borrar la cuenta, escribinos a baratoyaba@gmail.com con el asunto “Borrar mi cuenta — BaratoYa”.
