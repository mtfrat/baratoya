# BaratoYa

Comparador unificado de precios (Precios Claros / CABA).

```bash
cd /workspace/micro-saas && source .venv/bin/activate
uvicorn baratoya.app:app --host 0.0.0.0 --port 8011
```

Flags pagos (off): ver `../shared/.env.example`.

Deploy gratis (Vercel Hobby, sin dominio y sin pagos): ver `DEPLOY.md`.
